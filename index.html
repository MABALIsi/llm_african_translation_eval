⚙️ Pipeline Technique

1
Corpus -- 2000 phrases paralleles francais/lingala/bambara (FLORES-200 + enrichissement manuel en 9 domaines)
2
Traduction -- LLaMA-3-8b et LLaMA-3-70b via API Groq (zero-shot et few-shot)
3
Evaluation auto -- Metriques BLEU et chrF avec sacrebleu
4
Annotation humaine -- Interface web Flask (adequation + fluidite, 1-5 etoiles)
5
Publication -- Code source et resultats sur GitHub

🔧 Technologies Utilisees

Python 3.10 Jupyter Notebook Flask HuggingFace Datasets sacrebleu API Groq LLaMA-3 Anaconda Git / GitHub Pandas

💻 Installer et Executer le Projet

# 1. Cloner le depot
git clone https://github.com/MABALIsi/llm_african_translation_eval.git
cd llm_african_translation_eval

# 2. Creer l'environnement
conda create -n llm_african_translation python=3.10 -y
conda activate llm_african_translation
pip install -r requirements.txt

# 3. Lancer Jupyter
jupyter notebook

# 4. Lancer l'interface web
cd interface
python app.py
# Ouvrir http://localhost:5000
